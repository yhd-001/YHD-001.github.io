PROJECT 01

云端仓管系统

Web 系统数据同步Node.js真实截图
真实运行截图 · 已脱敏　查看完整案例 →
痛点
元器件出入库与库存靠人工登记，多人同时使用时数据不同步。
做法
用 Node.js 原生模块自建 HTTP 服务与 34 个接口，做带角色权限、多班组独立库存、Excel 导入导出与数据分析的 B/S 系统，兼容内网 Win7 离线环境。
结果
支撑 105 人日常使用、覆盖 10 万级物料，出入库记录可追溯。
Web 系统出入库 / 库存多人访问数据同步10 万级物料零第三方依赖
已投入公司内网实际使用　·　在线交互演示 ↗
PROJECT 02

生日团建网页

前端页面可视化交互真实截图
真实运行截图 · 演示版已脱敏　查看完整案例 →
痛点
部门团建缺投屏即开即用、能带动全场的互动页面，现场无服务端与网络。
做法
单文件 HTML 零依赖实现三卡随机抽奖、锦鲤奖池、任务与祝福、Canvas 烟花与 Web Audio 音效；组织者可在后台改名单、奖品、标题与密码，配置由 localStorage 持久化。
结果
免部署、0 元成本，已在部门团建现场投屏实际使用。
HTML / CSS / JS可视化交互零后端localStorageCanvas / Web Audio后台配置

PROJECT 03

快捷框图识字工具

桌面程序OCRPython
痛点
纸质工单与框图文字需人工逐条抄录，重复且容易出错。
做法
以得力扫拍仪作纸质工单 / 框图的图像采集端，自研 AI OCR 识别 + 结构化录入的桌面程序，输出可编辑结果。
结果
录入效率提升 3 倍，替代手工抄录，0 元额外成本。
PythonAI OCR得力扫拍仪桌面程序结构化录入
