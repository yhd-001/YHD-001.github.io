团队生日会互动页

一次部门团建活动的现场互动网页：单文件 HTML、零后端、零第三方依赖，双击即用。覆盖名单管理、随机抽奖、锦鲤奖池、任务与祝福、Canvas 烟花与后台配置，已在部门活动中实际使用。

localStorage配置本地持久化

二、要解决的问题

部门生日会需要一个投屏就能带动全场的互动页面：要能现场抽人、抽任务、送祝福，还要能随时改名单和奖品。现场不可能临时搭服务、装环境或联网，所以做成一个 HTML 文件发过去双击就能跑；活动组织者不是开发，名单、任务、奖品、标题都得能在页面上直接改，改完立刻生效、刷新也不丢。

三、实现方式

单页交互层HTML / CSS / 原生 JS
三卡滚动抽奖 · 结果弹窗
→
状态与池名单 / 任务 / 祝福 / 奖品四组池
不重复抽取，耗尽自动补充
→
本地持久化localStorage 数据版本 v12
后台配置即时同步到奖池

整套程序没有引入任何框架、CDN 或构建工具：动画用 Canvas + requestAnimationFrame，音效由 Web Audio 振荡器实时合成，配置存在浏览器 localStorage。现场只需一个浏览器，不需要服务端、不需要网络，也不需要安装任何东西。

四、功能模块

◈ 三卡滚动抽奖开始 / 停止双按钮控制，滚动速度递增，停牌后锁定寿星与任务
🐟 锦鲤奖池可设中奖总数，抽奖时随机分配，抽完即止，不超发
✉ 祝福与任务15 条互动任务 + 20 条祝福语随机组合，结果弹窗分色高亮展示
🎆 Canvas 烟花粒子重力与拖尾动画，中奖时触发连发礼花，窗口缩放自适应
🔊 Web Audio 音效振荡器实时合成中奖提示音，用增益包络淡入淡出消除开关爆音
⚙ 后台管理面板页面标题 / 期数、名单、任务、祝福语、奖品、锦鲤数量、管理密码均可配置
💾 本地数据带版本号的数据结构、增删改查、重置与导入，刷新不丢配置
🔒 轻量登录齿轮入口 + 口令校验，避免现场误触改动奖池配置

五、技术难点与我的处理

  • 不重复抽取：维护剩余名单 / 任务 / 祝福三个独立池，抽出即从池移除；池耗尽时自动重置并洗牌，避免同一轮重复或中途卡死。
  • 后台改动不打断进行中的抽奖：仅在未开始抽奖时立即同步奖池，进行中的一轮沿用已加载的池，防止现场改名单导致结果错乱。
  • 配置刷新不丢：统一 loadData / saveData 读写 localStorage，带数据版本号，默认值与用户配置分离，重置可一键回到初始状态。
  • 音效爆音：不直接开关振荡器，改用 setValueAtTime + exponentialRampToValueAtTime 做淡入淡出包络，消除「咔」声。
  • 零依赖约束：图表、动画、音效、弹窗全部原生实现，不引 CDN，保证内网离线环境与任意一台电脑双击即可运行。
