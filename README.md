## 已做的脱敏

在线演示与截图来自系统真实运行，但已移除：实习单位名称与标识、内部 LOGO、真实工号与账号、会话信息、生产业务台账。演示数据为脱敏静态快照，写入类操作不生效。**生产环境源码、真实数据与部署包未在公开仓库提供。**

生日会互动页另做了：去除部门名称与活动期数、名单保持示例姓名、管理口令改为演示口令、**移除 3 个背景音乐文件以避免公开传播的版权风险**（保留页面内置的 Web Audio 合成音效）。桌面上的原始程序未做任何修改。
